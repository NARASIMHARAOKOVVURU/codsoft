Network Packet Analyzer

Task 1 - Cyber Security Mini Project

Project Description

A Network Packet Analyzer is a Python application that captures network packets, inspects them, and displays important information such as Source IP, Destination IP, Protocol Type, Ports, Packet Length, and Payload. It helps users understand how network communication works.

Objectives

  • Capture network packets.
  • Analyze network traffic.
  • Display Source and Destination IP.
  • Identify TCP, UDP and ICMP protocols.
  • Display packet payload.
  • Understand network communication.

Technologies Used

Technology Purpose
Python Main Programming Language
Scapy Packet Capturing Library
HTML Static Web Page
CSS Website Styling

Packet Information

Field Description
Source IP Sender IP Address
Destination IP Receiver IP Address
Protocol TCP / UDP / ICMP
Source Port Sending Port
Destination Port Receiving Port
Packet Length Packet Size
Payload Packet Data

Project Workflow

  1. Capture packets using Scapy.
  2. Extract packet information.
  3. Analyze protocols.
  4. Display packet details.
  5. Monitor network traffic.
